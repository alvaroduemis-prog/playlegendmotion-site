Política de privacidad

Última actualización: 14 de noviembre de 2026.

La aplicación "PlayLegendMotion" es una herramienta interna del canal de YouTube PlayLegendMotion. Su único uso es subir y programar los videos del propio canal mediante la API de datos de YouTube.

Datos a los que accede

Con la autorización del dueño del canal, la aplicación accede únicamente a la cuenta de YouTube de PlayLegendMotion para subir videos, establecer miniaturas, editar sus metadatos y consultar sus estadísticas públicas. No accede a cuentas de otras personas ni recopila datos personales de usuarios o espectadores.

Uso y almacenamiento

Los datos se usan solo para operar el canal. No se venden, no se comparten con terceros y no se usan con fines publicitarios. Las credenciales de acceso se guardan como variables secretas en el entorno de trabajo del dueño del canal.

Servicios de terceros

La aplicación usa los Servicios de API de YouTube. Al usarla se aplican las Condiciones del Servicio de YouTube y la Política de Privacidad de Google. El uso de la información recibida de las API de Google cumple con la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso

El acceso puede revocarse en cualquier momento desde https://myaccount.google.com/permissions.

Contacto

A través del canal: youtube.com/@playlegendmotion.
